
| 安全特性 | 说明 |

| **网络隔离** | 系统可完全运行于离线环境，无需互联网连接 |
| **本地存储** | 所有文档、向量、知识图谱均存储于本地服务器 |

## 🏢 企业级部署方案

### 方案一：完全离线部署

适用于：**涉密单位、金融核心系统、军工企业**

```yaml
环境要求：
  - 服务器: 16核 CPU, 64GB 内存, 500GB SSD
  - 网络: 完全离线，内网访问
  - LLM: Ollama + Qwen2.5/DeepSeek 本地模型

安全等级: ★★★★★
数据外泄风险: 0%
```

### 方案二：私有云部署

适用于：**大型企业、集团公司、多分支机构**

```yaml
环境要求：
  - Kubernetes 集群
  - 私有容器镜像仓库
  - 企业级对象存储

安全等级: ★★★★☆
弹性扩展: 支持
```

### 方案三：混合部署

适用于：**需要平衡成本与安全的企业**

```yaml
本地组件：
  - 文档存储和解析
  - 向量数据库
  - 知识图谱
  
可选云端：
  - LLM API (仅发送查询，不发送原文)
  
数据保护：
  - 敏感词过滤
  - 查询脱敏
```
